# Live Game · dirección de producto

El Live Game de IQBasket se diseña como dos experiencias conectadas por una única fuente de verdad:

- **Scorer**: captura ultrarrápida para una persona que no puede apartar la vista del partido.
- **Game Center**: consumo read-only para staff, jugadores, familias o seguidores autorizados.

El scorer prioriza tiempo de interacción, prevención y corrección de errores, continuidad ante cobertura irregular y mínimo cambio de contexto. El Game Center prioriza legibilidad, marcador, acta y secuencia narrativa del partido.

La evolución comercial natural es habilitar en una fase posterior un enlace de seguimiento limitado al partido. Ese acceso deberá usar una proyección pública explícita y un token temporal/revocable, nunca una sesión de usuario ni permisos implícitos sobre Player 360, wellness, nutrición u otros módulos privados.
